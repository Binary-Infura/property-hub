# BuilderBus Builder Dashboard Guide

## Overview
The BuilderBus Builder Dashboard is a dedicated portal for invited builders to manage property listings. It allows builders to create property drafts, upload images and brochures, and submit properties for admin approval.

## Accessing the Dashboard
- URL: `/dashboard/builder`
- Only invited builders can access this portal
- The dashboard is linked from the main homepage under "Builder Portal"

## Dashboard Features

### 1. Property Management
The dashboard provides a complete property management workflow:

#### **Three Main Tabs:**
- **Drafts** - Properties you're still working on
- **Submitted** - Properties waiting for admin review
- **History** - Approved or rejected properties

#### **Quick Stats**
At the top of the dashboard, you'll see:
- Number of draft properties
- Properties submitted for review
- Approved properties
- Total properties submitted

### 2. Adding a New Property

#### **Step 1: Click "Add Property"**
This opens the property details form where you'll provide:

**Basic Details:**
- **Project Title** (Required) - Name of the project/property
- **Configuration** - Select from 1 BHK to 4+ BHK
- **Location** (Required) - Area and city
- **Price** (Required) - Asking price (e.g., ₹45L)
- **Area** (Required) - Size in square feet
- **Property Age** - Age of the property

**Description:**
- Comprehensive description of the property, features, and highlights

**Amenities:**
- Add multiple amenities (e.g., Swimming Pool, Gym, Parking)
- Type the amenity and click "Add" or press Enter
- Click the × button to remove an amenity

**Property Images:**
- Upload multiple property photos (PNG, JPG, GIF up to 5MB each)
- Drag and drop or click to browse
- Preview images before saving
- Remove images by clicking the × button

**Brochure (Optional):**
- Upload a PDF, DOC, or DOCX file (up to 10MB)
- This is optional but recommended for detailed specifications

#### **Step 2: Save as Draft**
- Click "Save as Draft" to save your property
- You can edit it later before submitting
- Drafts are not visible to buyers yet

#### **Step 3: Review and Submit**
- After completing all details, go to the Drafts tab
- Click "Submit for Approval" when ready
- The property moves to the "Submitted" tab
- Admin team reviews and either approves or requests changes

### 3. Managing Properties

#### **For Draft Properties:**
- **Edit** - Make changes to any field
- **Submit for Approval** - Move to review queue
- **Delete** - Remove the property permanently

#### **For Submitted Properties:**
- **Edit** - Make changes if admin requests modifications
- **Delete** - Remove if no longer available
- Status shows "Under Review"

#### **For Approved/Rejected Properties:**
- **View Details** - See the final status
- **Edit** - For rejected properties, edit and resubmit
- **Delete** - Remove from listings

### 4. Admin Review & Feedback

**What Happens After Submission:**
1. Admin team reviews your property details
2. Verifies images quality and authenticity
3. Checks pricing and specifications
4. Approves or requests changes

**If Rejected:**
- You'll see the rejection reason in the feedback section
- Click "Edit" to modify based on feedback
- Resubmit for approval

**If Approved:**
- Property appears on BuilderBus platform
- Visible to consultants and buyers
- Listed in the "Approved" tab

## Best Practices

### Property Details
✓ Provide accurate and complete information  
✓ Use clear, professional descriptions  
✓ List all relevant amenities  
✓ Include realistic pricing based on market  

### Images
✓ Upload high-quality photos (minimum 1500x1000px recommended)  
✓ Include multiple angles (front, living areas, bedrooms, kitchen, balcony)  
✓ Ensure good lighting and composition  
✓ Avoid cluttered or blurry images  
✓ Include a brochure with floor plans if available  

### Descriptions
✓ Be specific about features and benefits  
✓ Mention unique selling points  
✓ Include nearby amenities (schools, transport, shopping)  
✓ Highlight property condition and recent renovations  

## Property Status Workflow

```
Add Property → Save as Draft → Edit/Review → Submit for Approval
                                                      ↓
                                            Under Review (Admin)
                                                      ↓
                                    ┌──────────────────┴──────────────────┐
                                    ↓                                      ↓
                                APPROVED                              REJECTED
                             (Live on platform)           (Feedback provided, can edit & resubmit)
```

## Dashboard Stats

The dashboard header shows real-time statistics:
- **Draft Properties**: Count of incomplete/unsaved properties
- **Submitted**: Properties waiting for admin review
- **Approved**: Successfully approved properties
- **Total**: All properties ever submitted

## Tips for Success

1. **Complete Profiles** - Fill all required fields before submitting
2. **Quality Images** - Professional photos increase approval chances
3. **Accurate Details** - Ensure all information is current and accurate
4. **Proactive Updates** - Update property status as changes occur
5. **Respond to Feedback** - If rejected, address feedback promptly
